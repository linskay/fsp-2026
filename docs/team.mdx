# 👥 Команда разработчиков

## «NO PHP — NO PROBLEMS — 2026»

Проект разработан в рамках официального хакатона Федерации спортивного программирования России командой инженеров, объединенных общим манифестом качества кода и современных технологических стандартов.

---

## 🏆 Манифест команды

1. **Строгая статическая типизация**: Мы исключаем неопределенности в рантайме. Основа нашего стека — **Java 21**, **Kotlin 2.0** и **TypeScript**.
2. **Чистая архитектура (Clean Architecture)**: Полное разделение слоев представления, бизнес-логики и данных на бэкенде, фронтенде и в мобильном клиенте.
3. **Безопасность и соответствие закону**: Вся обработка персональных данных строго изолирована и соответствует **152-ФЗ**.
4. **Инженерная эстетика**: Каждый элемент интерфейса платформы оформлен по официальному брендбуку ФСП с использованием моноширинной гарнитуры **JetBrains Mono**.
