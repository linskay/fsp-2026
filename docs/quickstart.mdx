# Быстрый запуск системы

Платформу можно запустить за считанные секунды с помощью готовых Docker-контейнеров или автономного дистрибутива.

---

## 🐳 Запуск через Docker Compose (Рекомендуемый)

Убедитесь, что на вашей машине установлен Docker и Docker Compose.

```bash
# 1. Клонирование репозитория
git clone https://github.com/linskay/fsp-2026.git
cd fsp-2026

# 2. Быстрый запуск production-окружения
docker compose -f docker-compose.prod.yml up -d
```

После старта контейнеров сервисы доступны по адресам:
- 🌐 **Веб-интерфейс (React 19)**: [http://localhost:3000](http://localhost:3000)
- ⚙️ **REST API & Swagger (Spring Boot 3)**: [http://localhost:8080/swagger-ui.html](http://localhost:8080/swagger-ui.html)
- 🗄️ **PostgreSQL 16**: `localhost:5432` (db: `career_arena`, user: `fsp_user`)

## 📱 Запуск мобильного приложения (Android)

Проект мобильного приложения расположен в папке `mobile/`.

```bash
# Запуск валидации и сборки мобильного клиента
python scripts/bootstrap_mobile.py

# Сборка debug APK через Gradle
cd mobile
./gradlew assembleDebug
```
