### 1. AI Summary (Мультимодельный ИИ-анализ)
Генерация технического портрета кандидата на базе LLM (Gemini 1.5 Flash, YandexGPT Pro, OpenRouter, Ollama) с использованием паттерна Strategy.

<AccordionGroup>
  <Accordion title="GET /api/v1/ai-summary/candidate/{candidateId}">
    **Получение или генерация AI-Summary для кандидата**
    - **Параметры пути:** `candidateId` (UUID) — идентификатор соискателя
    - **Ответ 200 OK:** JSON с сгенерированным резюме, оценкой чистоты кода (`codeQualityScore`), грейдом и списком подтвержденных сильных сторон.
  </Accordion>
  <Accordion title="POST /api/v1/ai-summary/generate">
    **Динамическая генерация AI-портрета с выбором провайдера и фокуса**
    - **Тело запроса (JSON):**
      ```json
      {
        "candidateId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
        "provider": "YANDEX_GPT",
        "modelName": "yandexgpt-pro",
        "focus": "HIGH_LOAD_CORE",
        "customApiKey": "string (опционально)"
      }
      ```
    - **Фокусы анализа:** `HIGH_LOAD_CORE`, `ALGORITHMS`, `TECH_LEAD`, `BALANCED`
  </Accordion>
</AccordionGroup>

### 2. Assessments & Code Reviews (Технические задания и ревью)
Управление техническими заданиями, отправка решений соискателями, просмотр кода и вынесение вердикта ревьюером/тимлидом.

<AccordionGroup>
  <Accordion title="POST /api/v1/assessments/assign">
    **Отправка кандидату кастомного задания от работодателя**
    - Назначение практического таска с ограничением по времени (таймер) и опцией лайв-интервью в Яндекс Телемост.
  </Accordion>
  <Accordion title="GET /api/v1/assessments/candidate/{candidateId}">
    **Получение списка назначенных соискателю заданий**
    - Возвращает статус прохождения (`PENDING`, `IN_PROGRESS`, `SUBMITTED`, `REVIEWED`), дедлайн и привязанную вакансию.
  </Accordion>
  <Accordion title="GET /api/v1/assessments/employer/{employerId}">
    **Список заданий со стороны работодателя**
    - Фильтрация по статусам: *«Ожидает код-ревью»*, *«Пройдено»*, *«Отклонено»*.
  </Accordion>
  <Accordion title="GET /api/v1/assessments/submissions/{id}">
    **Получение отправленного решения кандидата**
    - Возвращает исходный код решения, язык программирования, время выполнения (runtime) и результаты автоматических тест-кейсов.
  </Accordion>
  <Accordion title="POST /api/v1/assessments/submissions/{id}/review">
    **Сохранение оценки ревьюера**
    - Вердикт: `HIRED` / `REJECTED`, приватный комментарий для HR-команды и официальный фидбек для соискателя.
  </Accordion>
</AccordionGroup>

### 3. Authentication & OAuth (Авторизация и SSO)
Многофакторная авторизация, внешние провайдеры (GitHub, Яндекс ID, HeadHunter), учетные записи и согласие на обработку ПДН (152-ФЗ).

<AccordionGroup>
  <Accordion title="POST /api/v1/auth/login">
    **Аутентификация по email и паролю**
    - Возвращает JWT access-токен с ролями `CANDIDATE` или `EMPLOYER`.
  </Accordion>
  <Accordion title="POST /api/v1/auth/register">
    **Регистрация нового пользователя**
    - Регистрация в PostgreSQL с фиксацией согласия 152-ФЗ.
  </Accordion>
  <Accordion title="GET /api/v1/auth/test-users">
    **Предзаполненные тестовые учетные записи**
    - Быстрый вход в 1 клик для соискателя (`candidate@fsp.ru`) и работодателя (`employer@fsp.ru`).
  </Accordion>
  <Accordion title="GET /api/v1/auth/oauth/github/url">
    **URL для входа через GitHub OAuth2**
    - Возвращает URL авторизации GitHub с правами чтения публичных репозиториев и профиля.
  </Accordion>
  <Accordion title="POST /api/v1/auth/oauth/github/callback">
    **Обработка callback от GitHub**
    - Обмен authorization code на токен, загрузка коммитов, расчет стартового ELO и ИИ-анализ.
  </Accordion>
  <Accordion title="POST /api/v1/auth/sync/github-profile">
    **Принудительная синхронизация профиля GitHub**
  </Accordion>
  <Accordion title="GET /api/v1/auth/yandex/login & GET /api/v1/auth/yandex/callback">
    **OAuth2 вход через Яндекс ID**
  </Accordion>
  <Accordion title="GET /api/v1/auth/hh/login & GET /api/v1/auth/hh/callback">
    **OAuth2 вход через HeadHunter (hh.ru)**
  </Accordion>
  <Accordion title="POST /api/v1/auth/sync/hh-resume">
    **Импорт резюме соискателя из HeadHunter API**
    - Автоматическое извлечение коммерческого стажа, стека технологий и зарплатных ожиданий.
  </Accordion>
  <Accordion title="GET /api/v1/auth/connections & DELETE /api/v1/auth/connections/{provider}">
    **Управление привязанными внешними профилями**
    - Просмотр списка и отвязка сервисов (GitHub, hh.ru, Яндекс ID, ФСП).
  </Accordion>
  <Accordion title="GET /api/v1/auth/privacy-policy">
    **Положение об обработке ПДН (152-ФЗ РФ)**
  </Accordion>
</AccordionGroup>
