# Интеллектуальный анализ кандидатов

Для объективной и беспристрастной оценки квалификации соискателей платформа включает модуль интеллектуального скоринга на базе современных больших языковых моделей (LLM).

---

## 🤖 Мультипровайдерная архитектура

Система не зависит от конкретного поставщика ИИ и поддерживает горячее переключение между провайдерами:

- **Google Gemini 1.5 Flash / Pro**: Высокая скорость и глубокий анализ сложных архитектурных навыков.
- **OpenRouter (Meta Llama 3.3, Mistral, Qwen)**: Независимый шлюз для доступа к ведущим открытым моделям мира.
- **Ollama (Локальный контур)**: Полная изоляция персональных данных и автономная работа на серверах внутри РФ.
- **YandexGPT 3 / 4**: Отечественная языковая модель с отличным пониманием российской терминологии и специфики соревнований ФСП.

---

## 🎯 Единый системный промпт ФСП

Оценка формируется строго в структурированном формате JSON:

```json
{
  "matchScore": 94,
  "summary": "Кандидат обладает подтвержденным 1-м спортивным разрядом ФСП и глубокими знаниями Spring Boot и PostgreSQL.",
  "strengths": [
    "Опыт решения олимпиадных задач высокой сложности (ELO 2540)",
    "Практический опыт с многопоточностью и смешанной сборкой Java/Kotlin"
  ],
  "recommendations": [
    "Рекомендовано первичное техническое интервью по проектированию распределённых очередей"
  ]
}
```

---

## 🛡️ Отказоустойчивость и Circuit Breaker (Graceful Degradation)

- **Zero-Failure Fallback Engine**: Если во внешнем окружении не переданы действующие токены коммерческих API (Gemini/OpenRouter/Telegram) или провайдер возвращает HTTP 429/500/Таймаут, Circuit Breaker автоматически переключается на встроенный детерминированный симулятор технического скоринга.
- **100% стабильность демонстрации**: Платформа гарантированно возвращает реалистичный детальный JSON-анализ даже в закрытом автономном контуре.
- **Кэширование и проксирование**: Запросы к внешним API (LeetCode, GitHub) защищены прокси-маршрутами с многоуровневым fallback-кэшем для предотвращения исчерпания Rate Limits.
