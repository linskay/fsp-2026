FSP Career Arena 2026

Java 21 Kotlin 2.0 React 19 Android Compose

FSP Career Arena — это инновационная цифровая платформа, объединяющая соискателей в сфере программной инженерии, ведущих работодателей и Федерацию спортивного программирования России.

Платформа решает ключевую проблему современного ИТ-рекрутинга: достоверность практических навыков кандидата. Вместо нерепрезентативных резюме система предоставляет верифицированный цифровой паспорт со спортивными разрядами ФСП, рейтингом ELO, алгоритмическими испытаниями в реальном времени и мультипровайдерным ИИ-скорингом.

🌟 Ключевые возможности

Верифицированный профиль ФСП
Официальные спортивные разряды (1-й, 2-й, КМС, МС), динамический ELO-рейтинг (1200–2800) и история официальных турниров Федерации.
Code Arena IDE
Интерактивная среда тестирования кода с компиляцией и оценкой решений алгоритмических задач в реальном времени.
Мультипровайдерный ИИ-анализ
Единый промпт ФСП и переключение между Gemini, OpenRouter, Ollama и YandexGPT для глубокой оценки стека соискателя.
Нативное мобильное приложение
Полнофункциональный мобильный клиент на **Kotlin 2.0 + Jetpack Compose + Clean Architecture** для соискателей и рекрутеров.
«Слепой» наем (Blind Hiring Mode)
Zero-Bias режим работодателя: временное скрытие ФИО и фотографий до взаимного оффера с фокусом на ELO, разрядах ЕВСК и решенных задачах.
Веб-хуки интеграций (Webhooks)
Асинхронная отправка событий в ATS компании (Сбер, Яндекс, Huntflow) при принятии офферов с подписью HMAC-SHA256.

📸 Интерфейс платформы

1. Главная страница и модель обратного найма

Цифровой портал обратного рекрутинга с прозрачными рублевыми вилками и автоматической проверкой статуса бэкенда в реальном времени.

2. Личный кабинет атлета и официальный паспорт ФСП

Подтвержденный профиль кандидата с ELO-рейтингом, спортивным разрядом (КМС/МС), динамикой киберспортивных турниров, верификацией коммитов GitHub и мультипровайдерным ИИ-портретом.

3. Интерактивная среда Code Arena IDE (LeetCode & ФСП)

Встроенная веб-IDE на базе Monaco Editor с запуском тестов, подсветкой синтаксиса, получением подсказок и автоматической фиксацией результатов в паспорте спортсмена.

4. Рабочее место работодателя и режим «Слепого» найма

Панель рекрутера с умным ATS-поиском по ELO, Explainable Match соответствием, фильтром по победам в официальных турнирах и переключателем Zero-Bias (скрытие персональных данных до оффера).

🧱 Основные компоненты системы

1. Серверная часть (Backend)

  • Технологии: Java 21 LTS + Kotlin 2.0.20 + Spring Boot 3.3.4.
  • База данных: PostgreSQL 16 с версионированием миграций через Flyway.
  • Взаимодействие: Полная совместимость смешанного кода Java и Kotlin без накладных расходов во времени выполнения (Zero-overhead interoperability).

2. Веб-интерфейс (Frontend)

  • Технологии: React 19 + TypeScript + Vite + Tailwind CSS.
  • Типографика: Фирменный моноширинный шрифт JetBrains Mono по официальному брендбуку ФСП.
  • Компоненты: Интерактивная Арена с подсветкой синтаксиса, дашборды для соискателей и рекрутеров, режим «Слепого» найма (Blind Hiring Zero-Bias), Explainable AI Match и модальные окна Телемоста.

3. Мобильный клиент (Android)

  • Технологии: Kotlin 2.0 + Jetpack Compose (Material 3) + Clean Architecture + MVVM + StateFlow.
  • Сетевой слой: Retrofit 2 + Moshi + OkHttp.

4. Интеллектуальный анализатор (AI Engine)

  • Мультипровайдерная интеграция с поддержкой Google Gemini, OpenRouter, локальной Ollama и YandexGPT.
  • Автоматический расчет соответствия кандидата техническим требованиям вакансии на основе структурированного JSON-промпта.

Серверная платформа

Серверная часть платформы построена на современном стеке Java 21 (Temurin) и Kotlin 2.0.20 под управлением Spring Boot 3.3.4.

⚡ Гибридная компиляция Java + Kotlin (Best Practices)

Для максимальной производительности и гибкости проект использует смешанную сборку (Mixed Compilation). Это позволяет существующим корпоративным Java-компонентам бесшовно вызывать современные Kotlin-контроллеры и Data Classes:

<!-- Настройка плагина в pom.xml -->
<plugin>
    <groupId>org.jetbrains.kotlin</groupId>
    <artifactId>kotlin-maven-plugin</artifactId>
    <version>2.0.20</version>
    <configuration>
        <jvmTarget>21</jvmTarget>
        <compilerPlugins>
            <plugin>spring</plugin>
            <plugin>jpa</plugin>
        </compilerPlugins>
    </configuration>
    <dependencies>
        <dependency>
            <groupId>org.jetbrains.kotlin</groupId>
            <artifactId>kotlin-maven-allopen</artifactId>
            <version>2.0.20</version>
        </dependency>
        <dependency>
            <groupId>org.jetbrains.kotlin</groupId>
            <artifactId>kotlin-maven-noarg</artifactId>
            <version>2.0.20</version>
        </dependency>
    </dependencies>
</plugin>

🛡️ Безопасность и соответствие 152-ФЗ

  • Хранение паролей с использованием адаптивного алгоритма BCrypt с солью;
  • Аутентификация на основе JWT (JSON Web Tokens) с разделением прав доступа по ролям (ROLE_CANDIDATE, ROLE_EMPLOYER, ROLE_ADMIN);
  • Полное соблюдение требований 152-ФЗ «О персональных данных»: данные соискателей обрабатываются исключительно на серверах, расположенных на территории РФ, с возможностью отзыва согласия на обработку.

Полная спецификация REST API платформы

Интерактивная спецификация доступна в Swagger UI по адресу: /swagger-ui.html
Машиночитаемый формат: /v3/api-docs

1. Аутентификация, SSO и 152-ФЗ

POST /api/v1/auth/login — Вход в систему (JWT)
Аутентифицирует пользователя по паре email + пароль и возвращает stateless JWT токен с ролевыми клеймами (`CANDIDATE` / `EMPLOYER`).
POST /api/v1/auth/register — Регистрация нового аккаунта
Регистрирует нового соискателя или компанию с фиксацией согласия на обработку ПДН (152-ФЗ).
GET /api/v1/auth/test-users — Тестовые доступы
Возвращает список предзаполненных аккаунтов (`candidate@fsp.ru`, `employer@fsp.ru`) для мгновенного входа в 1 клик.
GET /api/v1/auth/privacy-policy — Политика конфиденциальности
Возвращает текст и регламент обработки ПДН по стандарту Федерации спортивного программирования России.
GET /oauth2/authorization/{provider} — Spring Security OAuth2
Инициализирует вход через GitHub, Яндекс ID или HeadHunter OAuth2.

2. Профиль пользователя и управление ролями (RBAC)

GET /api/v1/users/me — Текущая сессия пользователя
Возвращает данные авторизованного пользователя: ID, email, роль, привязанный профиль атлета/рекрутера, текущий ELO и спортивный разряд.
PUT /api/v1/users/profile — Обновление профиля
Обновляет ФИО, аватар и параметры безопасности пользователя.

3. Соискатели и кандидаты ФСП

GET /api/v1/candidates — Поиск и фильтрация атлетов
Универсальный эндпоинт поиска кандидатов с фильтрацией по query-параметрам: - `specialization`: BACKEND, FRONTEND, FULLSTACK, DEVOPS, HIGHLOAD - `grade`: JUNIOR, MIDDLE, SENIOR - `minElo`: минимальный ELO-рейтинг ФСП - `fspRank`: спортивный разряд ЕВСК (1-й, 2-й, КМС, МС)
GET /api/v1/candidates/{id} — Карточка кандидата
Возвращает верифицированный профиль с историей турниров, стеком и LeetCode-метриками.
GET /api/v1/candidates/{id}/export-pdf — Официальный PDF-паспорт ФСП
Автогенерация стандартизированного PDF-документа с символикой Федерации, подтвержденным ELO и разрядом для HR-отчетов.
GET /api/v1/candidates/{id}/elo-history — История изменения ELO
Возвращает временной ряд точек изменения рейтинга для построения графика соревновательного прогресса.

4. Вакансии работодателей

GET /api/v1/vacancies/search — Поиск вакансий
Поиск открытых позиций с обязательной рублевой вилкой зарплат (без скрытых условий) и требованиями к ELO.
POST /api/v1/vacancies — Создание вакансии (HR)
Публикация новой потребности компании с автоматической активацией алгоритма Explainable Matching.
POST /api/v1/employer/sync/hh-vacancies — Импорт вакансий из hh.ru
Импорт вакансий компании из HeadHunter API в 1 клик через токен работодателя.

5. Офферы и Обратный найм (Reverse Recruiting)

POST /api/v1/offers — Отправка прямого оффера с вилкой
Создает оффер от работодателя кандидату с поддержкой RFC 7231 ключа идемпотентности (`Idempotency-Key`) и защитой от дублирования.
GET /api/v1/offers/candidate/{id} — Офферы соискателя
Список полученных предложений кандидата со статусами (PENDING, ACCEPTED, DECLINED).
PUT /api/v1/offers/{id}/accept — Принятие оффера
Кандидат принимает оффер: снимается маскирование контактов по 152-ФЗ и шлется веб-хук во внешнюю ATS работодателя.
PUT /api/v1/offers/{id}/decline — Отклонение оффера
Мягкое отклонение предложения кандидатом с фиксацией обратной связи.

6. Веб-хуки и корпоративные интеграции (Webhooks)

POST /api/v1/webhooks — Регистрация веб-хука для ATS
Регистрирует URL для отправки нотификаций (Сбер, Яндекс, Huntflow, 1C:ЗУП, Telegram-боты). Защита заголовком `X-FSP-Signature` (HMAC-SHA256).
GET /api/v1/webhooks/employer/{id} — Список веб-хуков
Возвращает зарегистрированные веб-хуки с HTTP-статусами последней доставки.
POST /api/v1/webhooks/{id}/ping — Тестовый пинг
Проверяет доступность эндпоинта компании с отправкой проверочного пакета PING.
DELETE /api/v1/webhooks/{id} — Удаление веб-хука
Отзывает регистрацию веб-хука.

7. ИИ-портреты соискателей (Multi-Model AI Summary)

POST /api/v1/ai/generate-summary — Мультимодельная генерация
Использует паттерн Strategy для динамического переключения нейросетей (Google Gemini, YandexGPT, OpenRouter, Ollama) с системным фокусом (Highload, Алгоритмы, Тимлид).
POST /api/v1/ai/save-profile — Сохранение ИИ-резюме
Фиксирует сформированное досье в базе данных PostgreSQL соискателя.

8. Изолированная песочница и тестирование (Judge0 / Docker)

POST /api/v1/sandbox/execute — Запуск кода в песочнице
Изолированное выполнение решения в Docker-песочнице (`--net=none`, cgroups v2, лимиты памяти 256MB и времени 1000мс).
POST /api/v1/assessments/assign — Назначение тестового задания
Работодатель назначает алгоритмическую задачу с дедлайном и ссылкой на Яндекс Телемост.
POST /api/v1/assessments/review — Ревью и оценка решения
HR/Техлид выставляет вердикт (👍 / 👎) и пишет закрытую внутреннюю заметку.
